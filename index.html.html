Pipit Bot

Asisten cerdas untuk merangkum notulensi rapat, mengingatkan tugas harian/mingguan, dan merapikan file kerja Anda.

⚠️ The Chaos

  • Sering lupa mengerjakan tugas dan kewajiban harian/mingguan.
  • Tidak punya waktu untuk membuat notulensi atau ringkasan rapat.
  • File dan dokumen pekerjaan menumpuk berantakan dan sulit dicari.

✨ The Solution

  • Pengingat tugas otomatis yang dikirim langsung via Email.
  • Integrasi dengan Google Meet untuk rekam dan rangkum rapat instan.
  • Mengorganisasi file secara otomatis dengan sistem Approval (Human-in-the-Loop).

Core Capabilities

📹

Meet Notetaker

Terhubung langsung ke Google Meet untuk merekam diskusi dan menyusun notulensi rapat secara otomatis.

📁

Smart File Organizer

Merapikan dokumen Anda ke folder yang tepat. Selalu meminta persetujuan Anda sebelum memindahkan file.

📧

Task Reminder

Mengelola jadwal Anda dan mengirimkan pengingat tugas harian atau mingguan tepat waktu via Email.
